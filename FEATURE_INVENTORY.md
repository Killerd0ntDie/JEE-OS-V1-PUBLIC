# Feature Inventory

## CORE (Keep & Harden)
*Must exist for the app to function.*
- **Firebase Authentication:** Standard email/password + anonymous.
- **Firestore Data Layer:** Repositories for syncing user data.
- **Syllabus Tracker (Subject Pages):** The core record of chapter completion (Theory, DPP, PYQ).
- **Settings & Profile:** Target year, branch, daily quotas.

## IMPORTANT (Fully Integrated & Hardened)
*Core intellectual property of JEE OS.*
- **Daily Planner (PlannerEngine):** fully auto-generated by the AI Engine via multi-objective lookahead optimization.
- **Mistakes Log (Error Book):** Feeds directly into the Revision Engine.
- **Revision Engine:** Spaced repetition engine reacting to real events (Lectures, PYQs, Mistakes).
- **Mission Mode (Focus Timer):** Pulls real pending tasks from the Planner and handles completion seamlessly.
- **Neural Link (Knowledge Graph):** Advanced interactive visualization of the JEE syllabus with visual mastery indications.
- **Mock Tests Simulator:** Fully integrated exam simulator that auto-logs mistakes and updates mock test performance telemetry in real-time.

## OPTIONAL (Gamification & Polish)
*Enhances engagement but distinct from core logic.*
- **Gamification (XP, Levels, God Mode):** Tracks real educational milestones and includes "God Mode" xp multipliers for high streaks.
- **Detailed Analytics Charts:** Real telemetry from `AnalyticsEngine`.
