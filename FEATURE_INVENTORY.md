# Feature Inventory

## CORE (Keep & Harden)
*Must exist for the app to function.*
- **Firebase Authentication:** Standard email/password + anonymous.
- **Firestore Data Layer:** Repositories for syncing user data.
- **Syllabus Tracker (Subject Pages):** The core record of chapter completion (Theory, DPP, PYQ).
- **Settings & Profile:** Target year, branch, daily quotas.

## IMPORTANT (Refactor & Connect)
*High value, but currently flawed in execution.*
- **Daily Planner:** Currently manual. Must be rewritten to be auto-generated by the AI Engine.
- **Mistakes Log (Error Book):** Great UI, but needs to feed directly into the Revision Engine.
- **Revision Engine:** Currently uses basic spaced repetition. Needs to integrate with the Planner.
- **Mission Mode (Focus Timer):** Needs to pull real pending tasks rather than generic placeholders.

## OPTIONAL (Deprioritize for now)
*Nice to have, but not critical for production readiness.*
- **Gamification (XP, Levels):** Currently tracked, but provides little real educational value. Can distract from serious study.
- **Detailed Analytics Charts:** Keep basic stats, but complex D3/Recharts graphs should be postponed until real data flows accurately.

## REMOVE (Delete immediately)
*Fake, cosmetic, or distracting systems.*
- **Mock Tests Simulator (`MockTestsPage.tsx`):** A cosmetic sandbox using `localStorage`. Delete it until a real backend is ready.
- **Static AI Coach (`COACH_TEMPLATES`):** Delete fake motivational arrays. AI must read data or not exist at all.
- **Fake Initial Seeds:** Remove the massive auto-population of 25+ chapters in `initialSeeds.ts` for new users. Users should start with a pristine, empty-but-structured 100% syllabus template.
